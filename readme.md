## 快速体验

访问 https://qqchecker.tengkong.top 立即体验

## 一、这是什么

给 QQ 推送做批改的工具。推送写好后发过来，只需截图或复制文字在上面圈点勾画、写下修改意见，
再导出成一份**好看的批改稿**发回去，一眼就知道哪里要改、改成什么。

工具有**两条批改链路**，按素材形态挑一条用：

| 链路 | 什么时候用 | 入口 |
| --- | --- | --- |
| **图片批改**（默认） | 手上有**截图**。**拿不准就用它** —— 截图就是"发出去长什么样"的权威版本 | 左栏顶部「＋ 图片批改」 |
| **文字批注** | 手上有推送的**纯文字**（能复制粘贴），想逐字逐句改 | 左栏顶部「＋ 文字推送」 |

> **打开就是图片批改**。左栏顶部的「图片批改」是实心蓝按钮，排在第一位；
> 需要按文字改的时候，点旁边的「文字推送」。
>
> 首次打开是**干净的**：没有预置示例，一份空的图片批改草稿等着你把截图放进去。

## 二、先花 10 秒做两件小事

### 1. 填上你的名字（批注人）

**左栏最下方**有一条「批注人」，点开填上姓名，保存。

- 头像会自动取**姓名的后两个字**（"李小明" → 头像显示"小明"；"张三" → "张三"）。
- 这个名字会署在**导出的批改稿上**（抬头「批注人：李小明」），干事知道是谁批的。
- 之后每新建一条批注，都会记下当时的名字。
- 换人用同一个浏览器时，改一下名字即可；旧批注的署名不会被追改。

### 2. 挑一个主题

顶栏的☀/🌙图标，一键切换**浅色 / 深色**。夜里批改不刺眼。
选择会记住，下次打开还是这个主题。

```

├──────────┬────────────────────────────────┬──────────────────┤
│[图片批改][文字推送]                          │  批注清单         │
│  ▸ 截图…  │  [编辑] [批注] [预览]           │  [全部 ▾]         │
│  ▸ 秋季…  │                                │  ┌────────────┐  │
│          │        正文 / 图片画布          │  │① 错别字     │  │
│──────────│                                │  └────────────┘  │
│ [批注人]  │                                │                  │
└──────────┴────────────────────────────────┴──────────────────┘
```

> **新建入口在左栏最上方**（文档列表之上），第一眼就能看到；**「批注人」在左栏最下方**，
> 它是"设置"类的东西，和文档列表同属一个区域。
> 顶栏中间那个「已保存 / 未保存」是保存状态提示，旁边的「保存」按钮在**有改动时**才可点。

**手机 / 窄屏**（宽度小于 980px）会自动变成单栏，底部出现三个导航：

`文档` ─ `批改` ─ `批注`

点底部图标切换看哪一栏，一次专注一件事，不会被挤成一团。

## 四、文字批注：怎么用

### 第 1 步 · 把原文放进来

点「＋ 文字推送」→ 切到**编辑**页 → 把干事发来的推送**整段粘贴**进去。

可以直接从 QQ 聊天窗口复制粘贴，粘贴时工具会顺便尝试还原里面的 QQ 表情。

> 表情只求"看得见、判断得出用得合不合适"，不追求像素级还原。
> 要跟 QQ 里一模一样，请走**图片批改**（截图本身就是权威版本）。

### 第 2 步 · 拖选文字加批注

切到**批注**页 → 用鼠标**拖选**要批的那几个字 → 弹出小工具条 → 选一个类型
（错别字 / 措辞 / 格式 / 表情 / 赞赏 / 整体）→ 写意见、可选填「建议改成什么」→ 提交。

- 提交后正文里会出现**彩色高亮**，右侧清单里出现对应的卡片。
- 点右侧卡片 → 正文自动滚到对应位置；点正文里的高亮 → 右侧卡片高亮。
- 一条批注只能改一处，重叠区域会叠加显示。

### 第 3 步 · 预览

切到**预览**页，看干事拿到推送时的观感（不带任何高亮，纯阅读）。

### 第 4 步 · 导出

顶栏「导出」，文字文档给这些选项：

| 导出方式 | 长什么样 | 建议 |
| --- | --- | --- |
| **HTML · 整体批注式** | 正文里插①②③上标，文末按编号列全部意见 | 要归档、要打印 |
| **HTML · 段后批注式** | 每段下面紧跟这段的意见 | 发给干事看，最直观 |
| **PDF · 整体批注式 / 段后批注式** | 同上，走浏览器打印 | 正式存档 |
| **长图 · 整体批注式 / 段后批注式** | 同上，导成一张 PNG 长图 | 直接甩进 QQ 群 |
| **导出 JSON 存档** | 连批注一起备份 | 换设备 / 防丢 |
| **导入 JSON 存档** | 把存档读回来，直接进文档列表 | 换设备继续改 / 恢复备份 |
| **复制纯文本意见** | 只把意见文字复制出来（带"批注人"抬头） | 直接粘回 QQ 对话框 |

> 导出的 HTML 是**自包含**的：样式全内联，没有外部图片和脚本，发给任何人都能打开。
> 导出稿一律用**浅色**版式，方便打印。

## 五、图片批注：怎么用

### 第 1 步 · 把截图放进来

点「＋ 图片批改」，三种方式任选：

1. **直接 `Ctrl + V` 粘贴**（截图后最顺手，推荐）
2. 把图片文件拖拽到中间区域
3. 点「选择图片」挑文件

导入后图片会**自动等比压缩**（长边不超过 1500px），手机截图通常压完 200~500KB。

### 第 2 步 · 圈点勾画

工具栏从左到右：

| 工具 | 干什么 |
| --- | --- |
| **选择** | 点已有的标注，补写或修改它的意见 |
| **方框** | 框住一段话 / 一个区域，最常用 |
| **圆圈** | 圈住一个词或一个表情 |
| **箭头** | 指向某个具体位置，比画框更精确 |
| **画笔** | 自由划线，落笔即跟手 |
| **高亮框** | 拖一个框，框内铺半透明底色，醒目但不遮字 |
| **标点** | 在某个位置落一个标记点，不遮挡内容 |

旁边还能调**颜色**（红 / 橙 / 黄 / 绿 / 蓝 / 紫，或自定义取色）和**粗细**（细 / 中 / 粗）。

- **每种工具画完都会自动弹出意见框**，直接写意见就行 —— 不用先切回「选择」再点它。
- 只想划重点、暂时不写意见？按 `Esc` 关掉框，那条线照样留在图上。
- 每条带意见的标注会在图上显示一个**编号小圆标**，和右侧清单里的序号一一对应。
- `Ctrl + Z` 撤销上一步；工具栏还有「清空」「换图」；下拉可缩放
  （适应宽度 / 50% / 100% / 150%）。

> **换图会清空已有的圈画**，所以工具会先问你一句。如果只是想在原图上继续画，
> 别点「换图」。

### 第 3 步 · 导出

| 导出方式 | 长什么样 | 建议 |
| --- | --- | --- |
| **长图 · 标注 + 图下意见清单** | 图上保留圈画与编号，图下接一张编号意见清单 | **最常用**，一张图说清所有问题 |
| **长图 · 仅标注图形** | 只要图上的圈圈画画，不带文字清单 | 图已经够清楚时 |
| **长图 · 两侧索引线** | 图片居中，意见排在左右两栏，引线从卡片最近的一边牵到图上锚点。两栏会**自动配平**（谁那栏重就挪一张过去），不会一边堆满、另一边空着 | 意见多、要逐条对准 |
| **长图 · 就近索引（贴图）** | 意见卡贴着标注位置摆，短线指过去 | 意见集中在局部时 |
| **打印 / 存为 PDF** | 同「标注 + 清单」内容，输出 PDF | 正式存档 |
| **导出 JSON 存档** | 连图带标注一起备份 | 换设备 / 防丢 |
| **导入 JSON 存档** | 把存档读回来，直接进文档列表 | 换设备继续改 / 恢复备份 |
| **复制纯文本意见** | 只复制意见文字，带位置提示（如「图左上」） | 粘回 QQ |

## 六、保存与文档管理

### 保存：点一下才落盘

这个工具**不会**「改一个字就自动存」。批改稿是有**定稿语义**的，如果每次输入都悄悄写进去，
你根本分不清当前这版是不是发回给干事的那版。所以：

- 顶栏中间显示当前状态：**「已保存」/「未保存」**；
- 顶栏的 **「保存」按钮**在有改动时才可点（没改动时是灰的）；
- 改动后按 **`Ctrl + S`** 或点「保存」按钮，才真正写进本地存储；
- **带着未保存的改动**去切换文档 / 新建 / 删除 / 关闭页面时，会先弹出提示问你要不要保存 —— 不会静默丢东西。

> 左侧列表里，还没落盘的文档会带一个「未保存」小标记。

### 文档管理

- 左侧列表按**最近修改**排序，每条显示「文 / 图」类型标记、修改时间和批注条数。
- 鼠标移到某条上，右侧出现 **×** 可以删除该文档（会二次确认）。
- 点顶栏的标题输入框可以改推送标题 —— 标题只用来在列表里识别，不进正文。
- 关掉浏览器再打开，**已保存**的内容都还在（未保存的改动会丢，所以记得点保存）。

## 七、数据存在哪

- 全部存在浏览器的 **LocalStorage**，配额约 **5MB**，**只在这台电脑的这个浏览器里**。
- 一条文字推送几乎不占空间；**图片占地方**，压缩后每张约 200~500KB，
  大概能放 **8~15 张**截图。
- **清空浏览器数据会一并清掉**。重要的批改稿请及时**导出**，或定期用
  「导出 JSON 存档」做备份；要恢复时用「**导入 JSON 存档**」把存档读回来即可 ——
  导入会直接进文档列表，如果和列表里某份**撞了 id**，会先问你是**覆盖**还是**另存副本**。
- 存储写满时工具会提示"本地存储空间不足"，此时先导出备份，再删掉旧文档。

## 九、常见问题

**Q：粘贴后表情变成了一串文字，没渲染成图标？**
A：说明这个表情不在工具的映射表里（QQ 自定义表情、GIF 表情包都不在）。
改用**图片批注**最稳。

**Q：`[重要]`、`3/4` 这种也被当成表情了吗？**
A：不会。只有确实命中 QQ 表情表的写法才会渲染，`[重要]`、`3/4` 一律按普通文字处理。

**Q：`/微笑` 没被识别？**
A：如果斜杠后面紧跟着中文（比如 `/左太极走起`），工具**故意不识别** ——
避免把"优点/弱点"这类正文误吞掉。改用中括号写法 `[微笑]` 即可。

**Q：改了原文，之前的批注会不会乱？**
A：不会。批注锚点绑在**原始文本的字符位置**上，与表情怎么渲染无关。
改完原文切回批注页时会自动校正位置；实在对不上的会标成「原文已改动」，
绝不静默丢弃，你可以「重新指定」或「转为整体意见」。

**Q：导出的长图很大怎么办？**
A：图片导出是按原图像素绘制的，截图越长图越大。发 QQ 前可以先用系统的图片工具压一下。

**Q：手机上能用吗？**
A：能。窄屏会自动变成单栏 + 底部导航。不过手机浏览器对 LocalStorage 更严格，
建议正文批改在电脑上做，导出的批改稿在手机上看。

**Q：为什么我改了半天，关掉重开却没了？**
A：因为**改了不等于存了**。这个工具刻意不做自动保存（避免分不清哪版是定稿）。
看顶栏：显示「未保存」就说明还没落盘，点一下「保存」或按 `Ctrl + S` 即可。
切换文档、新建、删除、关页面时若还有未保存改动，工具都会先拦你一下。

**Q：第一次打开怎么是空的？示例呢？**
A：示例已全部移除，**首次打开就是干净的一张白纸**。想试手，随便粘一段推送文字，
或直接 `Ctrl + V` 贴一张截图进来即可。

```bash
# 合计 311 项断言，六套全绿
```

> 浏览器端的几套依赖本机 Edge，路径写在脚本里：
> `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
>
> **这个环境里的 `Edit` 偶发不落盘**：改完关键行，务必用 grep / node 复核一次，
> 再跑测试。已经因此吃过两次亏（一次是 CSS 规则没写进去导致两个按钮长得一样，
> 一次是 JS 分支没换掉导致引用了一个已删除的常量，直接抛异常）。

### 三条地基（改代码前请先记住）

1. **文字批注的锚点一律是「原始纯文本 `raw` 的字符偏移」**，与表情如何渲染无关。
2. **图片标注的坐标一律是「0~1 归一化比例」**，渲染时乘回图片尺寸。
3. **`STATE.dirty` 是"存没存"的唯一真相**：任何改动只 `markDirty()`，
   只有用户点「保存」或 `Ctrl+S` 才 `store.setDoc()`。别偷偷加自动落盘。

守住这三条，无论怎么改 UI、加主题、加功能，批注都不会错位，也不会悄悄丢改动。
